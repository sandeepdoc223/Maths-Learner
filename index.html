How students access courses

  1. Agents register and create students OR provide student credentials.
  2. Students login with: Student ID/email + Agent ID + Agent password.
  3. To enroll in a paid course, student provides Student ID and will be redirected to Stripe Checkout.
  4. After payment is successful the server confirms and student's course is enrolled.

This demo uses local SQLite and Stripe test keys. Do NOT use this as-is in production without secure deployment and best practices.
